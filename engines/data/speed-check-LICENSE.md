# Bundled speed-check clip

`speed-check-ar.wav` is derived from Google FLEURS, Arabic (`ar_eg`), test row 0.
Dataset: https://huggingface.co/datasets/google/fleurs
FLEURS authors: Alexis Conneau et al., Google (2022).
Paper: https://arxiv.org/abs/2205.12446
License: Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/

Changes: converted to mono 16 kHz signed 16-bit PCM and trimmed from 8.16 to
8.00 seconds for the local CPU speed check. No meeting audio is included.
This read Modern Standard Arabic clip measures inference speed; it does not
establish Saudi dialect accuracy or Arabic/English code-switching quality.
